# Car Mod Calculator & Configurator

Interactive web app for car enthusiasts to estimate modification budgets, parts compatibility and performance gains.

## Features
- Choose parts by category (engine, suspension, brakes, wheels)
- Live total cost, remaining budget and budget bar
- Power (hp) and handling gain calculation
- Compatibility checks: for example, a turbo kit needs an ECU remap and injectors, and a turbo cannot be combined with a supercharger
- Works offline in any browser

## Run
Open `index.html` in a browser. No install needed.

## Customise
Edit the `PARTS` array at the top of `script.js` to add parts, prices and rules.

## Tech
JavaScript, HTML5, CSS3, DOM manipulation
